# KITE website image specifications

The Studio CMS is the source of truth for artwork. Use these ratios everywhere so the Graphic Design team can prepare files once.

| Slot | Ratio | Suggested size | Notes |
| --- | --- | --- | --- |
| Project cover | 4:3 | 1600×1200 | Portfolio tiles, latest work |
| Project gallery | 3:2 | 1800×1200 | Project interiors |
| Case study hero | 16:9 | 1920×1080 | Case study header |
| Service image | 4:3 | 1600×1200 | Horizontal services slides |
| Client logo | flexible | PNG, ~160×64 display | Transparent background |

Accepted types: JPG, PNG, WebP, SVG. Maximum 8MB per file.

Do not invent project photography. Empty slots stay empty until a file is uploaded in Studio.
